## 这个版本新增

**设置窗口**（右键菜单 → 偏好设置…，或面板底部齿轮）

- 三栏参数台：左栏导航、右侧参数区，和主面板同一套深色仪表语言
- 开机自启开关（之前藏在右键菜单里）
- 预警阈值 −/+ 步进：CPU 阈值 100–800%、持续时长 1–15 分钟
- 11 个 agent 逐个开关，关掉的不参与归因
- 底部：打开规则文件、恢复默认、保存并重启

**菜单栏可读性**

- 温度文字改用系统自适应的 labelColor，之前彩色数字在毛玻璃菜单栏上糊成一片
- 档位信息改成前面一个 6pt 系统色圆点（绿/黄/橙/红）

**面板交互**

- 雪花按钮默认带淡底和描边，一眼能看出能点；hover 变琥珀
- 整行可点，展开子进程明细：每个子进程的名字和 CPU、根 PID、进程总数
- 行尾加 chevron 提示可展开

**弹窗定位**

- 修了弹出时向上生长、盖住菜单栏的问题（show 前强制布局并定死尺寸）

## 安装 / 升级

```bash
brew upgrade --cask luogao/tap/hotpot
```

首次安装：

```bash
brew install --cask luogao/tap/hotpot
```

## 说明

- ad-hoc 签名，无 Apple 公证；cask 装完会自动去掉 quarantine，直接能用
- 只支持 Apple Silicon + macOS 13+
- 设置改动点「保存并重启」才生效（规则在启动时读一次）
