## 这版修了你提的 8 条

**1 · 去掉圆角三角**
面板底部端口提示的警告三角图标删了，改纯文字标签。

**2 · 面板可以滚动了**
页头（状态 + 温度读数）和页脚固定，中间的 agent 列表 + 端口区滚动。agent 多、展开明细、端口多都不会再把设置按钮挤出去。

**3 · 设置页放大加宽**
- 窗口 580 → **640 宽**，字号整体上调一档（正文 11 → 12.5/13.5）
- 左栏三项**可点了**：01 通用 / 02 预警 / 03 Agent 是分区导航，点击滚到对应区块并高亮。它们本来就只是导航，之前不可点所以看着像摆设
- 行高、参数值字号同步放大

**4 · 支持 Pi + 已安装检测**
- 新增 Pi（pi coding agent）识别。短名字不能靠子串匹配（`pi` 会吃掉 pip / ping / python），加了 `bin` 字段做 basename 精确比对
- 每条 agent 规则加了安装路径检测（`~/.pi/agent`、`~/.claude`、`/Applications/Cursor.app` 等），设置页标注「已安装 / 未安装」，已安装的默认开启监控
- 老用户的 rules.json 会自动补上新增的 agent，原有开关状态不动

**5 · 设置页两个 bug**
- **减号点不动**：−/+ 改成一组带分隔线的 28×28 按钮，`contentShape` 明确命中区
- **没保存却"自己保存了"**：窗口复用导致 @State 残留上次改动。现在每次打开设置都重建视图，回到磁盘上的真实状态

**6 · 页脚**
面板和设置页底部都加了：版本号（点击去 Releases）、GitHub 仓库链接、© 2026 luogao。

**7 · README**
「灵感来自 WhoIsCooking」从标题下方移到文末 License 之后。

**8 · 端口监控**
之前只在检测到「残留」服务时显示，你机器上没有残留就什么都看不到，像功能没做。现在改为**列出所有开发服务占用的端口**（node / vite / python …），终端已关的额外标「残留」，可一键关闭。
