## 设置页滚动样式和面板统一

抽了一个 `ScrollFade` 容器，两处共用：

- 系统滚动条隐藏
- 底部 36pt 半透明 veil，滚到底自动消失
- 底部留 26pt，最后一行不贴边

顺带修了首帧不显示遮罩的问题（之前把状态变更包在 `withAnimation` 里，离屏快照拍到的是动画起点）。
